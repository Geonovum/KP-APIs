# Werkgroep Historie

Werkgroep van het Kennisplatform API's over **historie, mutaties, tijdreizen en verantwoording** in de gegevensuitwisseling via API's.

Aanmelden voor de werkgroep of op de hoogte gehouden worden kan via: **api@geonovum.nl**

## Doel

De huidige Nederlandse overheids-API-standaarden bieden nog nauwelijks invulling voor historie ten opzichte van de mogelijkheden van StUF-ebMS en Digikoppeling. De werkgroep wil de **interfacing** invullen (hoe ziet de gegevensuitwisseling via API's eruit) en daaruit **generieke, herbruikbare bouwstenen** extraheren, voortbouwend op bestaande initiatieven en standaarden.

Aandachtsgebieden (concept):

1. **Bijhouden / registreren**: registreren, wijzigen, corrigeren, intrekken/onttrekken/ongedaan maken, beëindigen
2. **Raadplegen / bevragen** (inclusief tijdreizen)
3. **Verantwoording**

Aanpalende thema's: bitemporaliteit en typen tijd, herleidbaarheid/herhaalbaarheid, de samenhang met modellering, synchronisatie, en een gedeelde vocabulaire/definities.

## Scope en uitgangspunten

- Blijven binnen het kennisdomein van de API's / gegevensuitwisseling; niet verzanden in een "ultiem historiemodel".
- Voortbouwen op bestaande bouwstenen (o.a. Uit Betrouwbare Bron, NEN 3610, JSON-FG, Federatief Datastelsel).
- Voorkeur voor abstracte patronen met een minimale set aannames over de onderliggende datastructuur.
- Opleveren wat vandaag al implementeerbaar is.
